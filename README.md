
\# Dulce Click – Sistema de Gestión de Inventario



\## Descripción



Dulce Click es un sistema de gestión de inventario desarrollado para apoyar la administración de productos de un emprendimiento dedicado a la comercialización de dulces, snacks, chocolates, bebidas y productos de confitería.



El sistema busca mejorar el control de las existencias, reducir errores en el registro de información y facilitar la consulta de los productos.



\## Módulo seleccionado



\*\*Gestión de Productos\*\*



El módulo permitirá registrar, consultar, actualizar, eliminar y buscar productos del inventario.

\## Flujo de ramas



El proyecto utilizará un flujo basado en GitHub Flow.



La rama `main` será utilizada para mantener una versión estable del proyecto.



Los nuevos cambios se desarrollarán mediante ramas independientes. Para las funcionalidades se utilizará una nomenclatura descriptiva, por ejemplo:



`feature/registrar-producto`



`feature/consultar-productos`



`feature/actualizar-producto`



`feature/eliminar-producto`



Una vez finalizado un cambio se realizará un commit y posteriormente se abrirá un Pull Request hacia `main`.



\## Integración continua



El repositorio contará con un pipeline básico mediante GitHub Actions.



El pipeline se ejecutará automáticamente cuando se realice un `push` o un Pull Request, verificando inicialmente la estructura básica del proyecto.
